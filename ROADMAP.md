# Roadmap

Design notes for agreed-but-not-yet-built features. Keep entries short and delete them
when shipped (the git history remembers).

The four-round presentation overhaul ("dark bistro menu + lane colours": style + front page,
shelves, Cook mode + reader, This week + aisle shopping) shipped 2026-11-27 — see CLAUDE.md →
*Presentation layer*. A full consistency audit followed the same day (honest gluten-free
tags, buyable shopping lines, recipe shape). Decided against: "recently cooked" / favourites.

Follow-ups:

- **Site icon in the new palette.** `branding/icon-brief.md` still describes the brick-red
  icon; update its colours (deep green-black `#101915`, cream `#f2e9d8`) and run
  `npm run icon` (needs the image API key). `docs/site.webmanifest` is regenerated by the
  same script and picks up the new background/theme colour from `scripts/lib/theme.mjs`.
- **Photo-style pilot.** Every photo comes from one prompt (same plate, linen, angle), so the
  grid reads as stock. Try either a varied style (surface/props from the cuisine, angle from
  the dish type) or one deliberate house style (e.g. overhead on a dark table, hard light) on
  ~6 recipes, compare them in the grid, then regenerate the rest with `npm run photos -- --force`.
- **Ingredient names that don't merge on the list.** A few spellings differ across recipes
  ("butter" / "cold butter", "serrano" / "serrano chile" / "serrano peppers"), so This week
  shows them as separate rows. Normalize the recipe lines (or add aliases) — the nutrition DB
  and any `planSwaps.replace` lines must be updated in step.
- **Homepage link preview is portrait** (`docs/og/_home.jpg`, derived from the README
  preview). If unfurls crop it badly, give `scripts/og-images.mjs` a dedicated 1200×630
  landscape capture for `_home`.
